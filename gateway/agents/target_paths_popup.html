Target Paths - Examples & Quick Reference

📝 Basic Syntax

Type Format Example
Local File path/to/file src/service.py
Azure DevOps File azdo:path/to/file azdo:src/service.cpp
Azure DevOps Query azdo:pattern filters azdo:keyword ext:cpp

💻 Local Files

Single local file
src/service.py
Read a single local Python file
Multiple local files
src/service.py src/utils/helpers.py tests/test_service.py
Read multiple local files (one per line)

☁️ Azure DevOps Files

Single Azure DevOps file
azdo:MergedComponents/pkggen/Microsoft-NanoServer-PowerShell.json
Read a specific file from Azure DevOps repository
Multiple Azure DevOps files
azdo:src/compute/ComputeServiceModule.cpp azdo:src/compute/ComputeService.h azdo:docs/ARCHITECTURE.md
Read multiple Azure DevOps files

🔍 Azure DevOps Queries

Keyword + file pattern
azdo:Microsoft-NanoServer-PowerShell AND file:*.json
Find all JSON files matching keyword
Extension filter
azdo:Microsoft-NanoServer-PowerShell ext:man
Find all .man files with keyword
Path filter
azdo:path:/MergedComponents Microsoft-NanoServer-PowerShell
Search only within specific folder
Advanced query with branch
azdo:branch:official/rs_sparc_ctr; path:/MergedComponents; Microsoft-NanoServer-PowerShell AND file:*.json
Full query with branch, path, keyword, and file pattern

🔀 Mixed Local + Azure DevOps

Local tests + Azure DevOps code
tests/test_service.py azdo:src/services/NetworkService.cpp azdo:src/services/NetworkService.h
Mix local test files with remote source files

⚙️ Query Filters

Filter Syntax Example
File pattern file:*.ext file:*.json
Extension ext:type ext:cpp
Path path:/folder path:/src
Branch branch:name branch:main
Operators AND, OR compute AND network

💡 Tips

  • ✅ Always use azdo: prefix for Azure DevOps files/queries
  • ✅ One path per line for multiple files
  • ✅ Queries return up to 10 matching files
  • ✅ Mix local and Azure DevOps freely
  • ❌ Don't use azdo: for local files
  • ❌ Don't forget : after filter keywords
  • ❌ Don't use dot in ext: (use ext:cpp not ext:.cpp)
